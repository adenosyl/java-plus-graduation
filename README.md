# Explore With Me

Репозиторий содержит все этапы выполнения дипломного проекта Яндекс Практикума.

Дипломный проект курса Java Backend Developer: Сервис для публикации, поиска и участия в мероприятиях.

## Технологии

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Docker
- Spring Cloud
  - Config Server
  - Eureka Discovery Server
  - Spring Cloud Gateway
  - OpenFeign

## Структура проекта

### Инфраструктурные сервисы

- `config-server` — централизованное хранение конфигурации сервисов;
- `discovery-server` — регистрация и обнаружение сервисов (Eureka);
- `gateway-server` — единая точка входа для клиентских запросов.

### Бизнес-сервисы

- `user-service` — управление пользователями;
- `event-service` — управление событиями и категориями;
- `request-service` — управление заявками на участие;
- `stats-server` — сбор и предоставление статистики просмотров.

### Общие модули

- `common` — общие DTO, исключения и вспомогательные классы;
- `stats-dto` — DTO сервиса статистики;
- `stats-client` — клиент для взаимодействия со stats-service.

### Прочее

- `ewm-main-service` — исходный монолитный сервис, использовавшийся до перехода на микросервисную архитектуру;
- `docker-init` — скрипты инициализации БД;
- `postman` — коллекции запросов для тестирования API.

### Взаимодействие сервисов
Внешние запросы поступают через `gateway-server` и маршрутизируются в соответствующие сервисы.

Для межсервисного взаимодействия используется OpenFeign и сервис обнаружения Eureka.

Основные взаимодействия:
- `event-service → user-service`
- `event-service → request-service`
- `request-service → event-service`

### Отказоустойчивость
Реализована базовая обработка недоступности зависимых сервисов:
- при недоступности `request-service` события продолжают отображаться;
- при недоступности `user-service` события продолжают отображаться с резервным значением автора события.
